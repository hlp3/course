## Что исправлено по итогам проверки

- Проверка 5 сначала возвращала 200 — забыли второй аргумент `201` у `response()->json()`; исправлено.
- Проверка 8 падала с 500, потому что правило `exists:categories,id` требовало таблицы в БД; заменили на `between:1,20` и пояснили, что реальная связь появится на лабораторной 6.
- Проверка 4 возвращала HTML — не был добавлен заголовок `Accept: application/json`; добавили во все запросы файла `requests.http`.
