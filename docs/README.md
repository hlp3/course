# ФактДня

Познавательный веб-сервис занимательных фактов: факт дня, кнопка «Удиви меня», категории и реакции пользователей.

## API

### Общие договорённости

- Базовый адрес: `/api`
- Стиль имён полей: `snake_case`
- Успешные ответы с данными обёрнуты в `data`
- Ошибка проверки данных — 422, формат:

```json
{
  "message": "Текст первой ошибки.",
  "errors": {
    "field_name": ["Текст ошибки для поля."]
  }
}
```

- Авторизация: Bearer-токен (Laravel Sanctum), будет уточнено на лабораторной 9.

### Эндпоинты

| Метод | URL | Что делает | Авторизация | Успех | Ошибки |
|---|---|---|---|---|---|
| GET | `/api/facts/daily` | Возвращает факт дня | Нет | 200 | 404 |
| GET | `/api/facts/random` | Возвращает случайный факт | Нет | 200 | 404 |
| GET | `/api/facts` | Список фактов, фильтр по `category_id` | Нет | 200 | 422 |
| GET | `/api/facts/{id}` | Один факт по id | Нет | 200 | 404 |
| GET | `/api/categories` | Список категорий | Нет | 200 | — |
| POST | `/api/register` | Регистрация пользователя | Нет | 201 | 422 |
| POST | `/api/login` | Вход в систему | Нет | 200 | 401, 422 |
| POST | `/api/logout` | Выход из системы | Да | 204 | 401 |
| POST | `/api/facts/{id}/reactions` | Поставить реакцию на факт | Да | 201 | 401, 404, 409, 422 |
| DELETE | `/api/facts/{id}/reactions` | Отменить свою реакцию | Да | 204 | 401, 404 |

### GET /api/facts — список фактов

**Query-параметры:**

- `category_id` — необязательный, integer, id существующей категории.
- `page` — необязательный, integer, по умолчанию 1.
- `per_page` — необязательный, integer, по умолчанию 10, максимум 50.

**Ответ 200:**

```json
{
  "data": [
    {
      "id": 1,
      "text": "Мёд не портится тысячелетиями.",
      "category": {
        "id": 2,
        "name": "Природа"
      },
      "likes_count": 12,
      "dislikes_count": 3,
      "created_at": "2025-01-01T12:00:00Z"
    }
  ],
  "meta": {
    "current_page": 1,
    "per_page": 10,
    "total": 42
  }
}
```

**Ответ 422:**

```json
{
  "message": "Выбранная категория не существует.",
  "errors": {
    "category_id": ["Выбранная категория не существует."]
  }
}
```

### POST /api/register — регистрация

**Тело запроса:**

```json
{
  "name": "Иван",
  "email": "ivan@example.com",
  "password": "secret123",
  "password_confirmation": "secret123"
}
```

**Правила полей:**

- `name` — обязательное, строка, от 2 до 50 символов.
- `email` — обязательное, валидный email, уникальный в таблице пользователей.
- `password` — обязательное, строка, минимум 8 символов, должно совпадать с `password_confirmation`.

**Ответ 201:**

```json
{
  "data": {
    "user": {
      "id": 1,
      "name": "Иван",
      "email": "ivan@example.com"
    },
    "token": "1|abcdef1234567890"
  }
}
```

**Ответ 422:**

```json
{
  "message": "Поле email уже занято.",
  "errors": {
    "email": ["Поле email уже занято."]
  }
}
```

### POST /api/facts/{id}/reactions — поставить реакцию

**Тело запроса:**

```json
{
  "type": "like"
}
```

**Правила полей:**

- `type` — обязательное, одно из значений: `like` или `dislike`.
- Бизнес-правило: у одного пользователя может быть только одна реакция на факт. Если реакция уже существует — 409.

**Ответ 201:**

```json
{
  "data": {
    "id": 5,
    "fact_id": 1,
    "type": "like",
    "likes_count": 13,
    "dislikes_count": 3
  }
}
```

**Ответ 409 (бизнес-правило):**

```json
{
  "message": "Реакция на этот факт уже существует."
}
```

**Ответ 422:**

```json
{
  "message": "Поле type должно быть like или dislike.",
  "errors": {
    "type": ["Поле type должно быть like или dislike."]
  }
}
```
