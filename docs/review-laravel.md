# Ревью ответа ИИ на запрос «сделай контроллер привычек для API на Laravel»

| № | Где | Проблема | Что нарушено | Как исправить |
|---|---|---|---|---|
| 1 | `store`: `Habit::create($request->all())` | Данные от клиента не проверяются, в модель уходит всё тело запроса | Не выполнены правила полей из контракта; в хранилище попадут лишние поля | Вызвать `$request->validate([...])` со всеми правилами из `README.md`, а результат передать в `create` |
| 2 | `store`: `Habit::create(...)` | Класса `App\Models\Habit` в проекте нет, база данных не подключена | При первом же запросе — фатальная ошибка / 500 | Работать через `App\Services\HabitRepository` и JSON-файл, как в задании 4 |
| 3 | `store`: `return response()->json($habit);` | Ответ без обёртки `data` | Нарушен п. «успешные ответы с данными обёрнуты в `data`» из контракта | `return response()->json(['data' => $habit], 201);` |
| 4 | `store`: код ответа по умолчанию 200 | Создание ресурса должно возвращать 201 Created | Нарушена таблица кодов из контракта | Явно передать 201 вторым аргументом `response()->json()` |
| 5 | `show`: `['error' => 'Not found']` | Формат ошибки не совпадает с форматом Laravel | Клиент, который парсит `message`, не увидит текст ошибки | `abort(404, 'Факт не найден.')` — Laravel сам соберёт `{"message": "..."}` |
| 6 | `show`: `Habit::find($id)` | Модели нет, миграции нет, таблицы нет — `find` не заработает | 500 вместо 200/404 | Искать в `HabitRepository::find((int) $id)`, отсутствие записи → `abort(404, ...)` |
| 7 | Пояснение к коду: «маршруты в `app/Providers/RouteServiceProvider.php`» | Такого файла в Laravel 11+ нет | Инструкция приведёт к ошибке «файл не найден» | Маршруты API регистрируются в `routes/api.php` после `php artisan install:api` |
| 8 | Контроллер целиком | Отсутствует метод `index`, хотя ИИ просили сделать контроллер ресурса | Не закрывает `GET /api/facts` (И4) | Добавить `index`, возвращающий `['data' => $this->facts->all()]` |
| 9 | Контроллер целиком | Нет конструктора с внедрением хранилища | Логика работы с данными попадёт в контроллер, что противоречит заданию 4 | `public function __construct(private HabitRepository $habits) {}` |
