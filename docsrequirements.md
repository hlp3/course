# Требования к веб-приложению «ФактДня»

## 1. Назначение

«ФактДня» — познавательный веб-сервис, который каждый день показывает один занимательный факт и позволяет быстро получить случайный факт из выбранной категории. Сервис рассчитан на студентов и взрослых пользователей, которым интересны короткие научно-популярные факты без длинных статей. Авторизованные пользователи могут выражать отношение к фактам через лайки и дизлайки.

## 2. Роли пользователей

| Роль | Что может делать |
|---|---|
| Гость | Просматривать факт дня, нажимать «Удиви меня», просматривать список категорий и факты внутри категории, открывать отдельный факт по прямой ссылке. Не может ставить реакции. |
| Пользователь | Всё, что может гость, плюс: регистрироваться, входить в систему, ставить лайк или дизлайк факту, менять и отменять свою реакцию. |

## 3. Границы MVP

| Входит в MVP | Не входит в MVP |
|---|---|
| Факт дня — один факт, одинаковый для всех в течение суток | Персональная лента фактов на основе интересов пользователя |
| Кнопка «Удиви меня» — случайный факт из базы | Комментарии к фактам |
| Список категорий и просмотр фактов внутри категории | Загрузка фактов самими пользователями (UGC) |
| Регистрация и вход по email и паролю | Восстановление пароля по email |
| Реакции: лайк и дизлайк, смена и отмена реакции | Репосты в соцсети и публичный API для внешних сервисов |
| Отдельная страница факта по прямой ссылке | Мобильное приложение |
| Наполнение базы фактов через seeders на этапе разработки | Админ-панель для управления фактами и категориями |
| Счётчики лайков и дизлайков у каждого факта | Email- и push-уведомления |

## 4. Пользовательские истории

- **И1.** Как гость, я хочу видеть «факт дня» на главной странице, чтобы каждый день узнавать что-то новое без лишних действий.
- **И2.** Как гость, я хочу нажать кнопку «Удиви меня» и получить случайный факт, чтобы быстро получить порцию интересной информации.
- **И3.** Как гость, я хочу видеть список категорий, чтобы выбрать интересующую тему.
- **И4.** Как гость, я хочу открыть категорию и просмотреть факты в ней, чтобы читать по интересной теме.
- **И5.** Как гость, я хочу открыть отдельный факт по прямой ссылке, чтобы прочитать его полностью и поделиться ссылкой.
- **И6.** Как пользователь, я хочу зарегистрироваться, чтобы мои реакции сохранялись.
- **И7.** Как пользователь, я хочу войти в систему, чтобы ставить реакции от своего имени.
- **И8.** Как пользователь, я хочу поставить лайк или дизлайк факту, чтобы выразить своё отношение.
- **И9.** Как пользователь, я хочу изменить или отменить свою реакцию, чтобы исправить случайный выбор.

## 5. Нефункциональные требования

- **Н1.** Ответ API на запросы получения фактов и категорий — не более 500 мс при 100 одновременных пользователях.
- **Н2.** Пароли пользователей хранятся только в виде хеша bcrypt; передача данных — только по HTTPS.
- **Н3.** Интерфейс корректно отображается на экранах шириной от 320 px до 1920 px без горизонтальной прокрутки.
- **Н4.** Приложение работает в последних двух версиях Chrome, Firefox, Safari и Edge.
- **Н5.** Запросы, изменяющие данные (регистрация, вход, реакции), требуют авторизации по токену.
- **Н6.** При недоступности API пользователь видит сообщение об ошибке на русском языке, а не пустой экран.

## 6. Критерии приёмки

### И1. Факт дня

```gherkin
# language: ru
Функция: Факт дня

  Сценарий: Гость открывает главную страницу
    Дано в базе есть хотя бы один факт
    Когда гость открывает главную страницу
    Тогда он видит один факт дня
    И видит название категории этого факта
    И видит количество лайков и дизлайков

  Сценарий: Факт дня не меняется в течение суток
    Дано гость открыл главную страницу и увидел факт дня
    Когда гость обновляет страницу через час
    Тогда он видит тот же самый факт дня

  Сценарий: Смена факта дня в полночь
    Дано наступила полночь по серверному времени
    Когда гость открывает главную страницу
    Тогда он видит новый факт дня, отличный от вчерашнего

  Сценарий: В базе нет фактов
    Дано в базе нет ни одного факта
    Когда гость открывает главную страницу
    Тогда он видит сообщение «Пока нет фактов»
    И не видит блока с фактом
```

### И2. Кнопка «Удиви меня»

- [ ] Кнопка «Удиви меня» видна на главной странице.
- [ ] При нажатии кнопки отображается случайный факт из базы без перезагрузки страницы.
- [ ] Если в базе только один факт, показывается он.
- [ ] Если в базе больше одного факта, два нажатия подряд показывают разные факты.
- [ ] Если в базе нет фактов, показывается сообщение «Пока нет фактов».
- [ ] Во время запроса к API кнопка блокируется, чтобы исключить двойное нажатие.

### И8. Реакция на факт

```gherkin
# language: ru
Функция: Реакция на факт

  Сценарий: Авторизованный пользователь ставит лайк
    Дано пользователь авторизован
    И у пользователя нет реакции на факт
    Когда пользователь нажимает «Лайк»
    Тогда счётчик лайков увеличивается на 1
    И кнопка «Лайк» становится активной

  Сценарий: Гость пытается поставить лайк
    Дано пользователь не авторизован
    Когда он нажимает «Лайк»
    Тогда он видит сообщение «Войдите, чтобы оценить факт»
    И реакция не сохраняется
    И счётчик лайков не меняется

  Сценарий: Пользователь меняет лайк на дизлайк
    Дано пользователь авторизован
    И пользователь уже поставил лайк факту
    Когда пользователь нажимает «Дизлайк»
    Тогда счётчик лайков уменьшается на 1
    И счётчик дизлайков увеличивается на 1
    И активной становится кнопка «Дизлайк»

  Сценарий: Повторная реакция того же типа
    Дано пользователь авторизован
    И пользователь уже поставил лайк факту
    Когда пользователь снова нажимает «Лайк»
    Тогда реакция отменяется
    И счётчик лайков уменьшается на 1
```
